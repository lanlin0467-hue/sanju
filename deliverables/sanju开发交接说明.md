交接日期：2026-10-19。接收方为负责 iPhone App 开发、后端部署和上架的开发者。本说明对应源码快照 `9837e5a`，聚焦已经实现的网页功能及继续开发所需信息。

## 产品和当前范围

用户准备分享一张生活照片或记录一个场景，却暂时找不到贴近心情的配文。三句接收画面和心情，提供三种语气的短句供选择。

- 输入：图片或文字画面描述至少一项，心情必填；图片和文字可以同时提供。
- 输出：鲁迅、莎士比亚（朱生豪式）、江南三种风格，各一句。它们是 AI 风格化生成内容，产品没有取得这些作者或相关权利人的背书。
- 操作：复制单句、单独重写一种风格；三种风格合计显示三次换句机会。
- 页面按手机浏览器布局。当前没有账号、历史记录、收藏、分享图、订阅或支付功能。
- 当前没有数据库；前端输入、图片预览、结果和历史句子保存在页面状态中，刷新丢失。

## 数据流程和模型配置

1. 浏览器将照片最长边控制在 1280 像素内，压成 JPEG，目标不超过 500 KiB；无法解码时给出错误。
2. 前端把 `mood`、可选 `scene` 和可选图片 data URL 发到本站接口。
3. 服务器先校验输入并消费一次请求预算，再把提示词及可选图片交给模型。
4. 当前调用 `https://openrouter.ai/api/v1/chat/completions`，代码配置模型为 `qwen/qwen3.7-flash`。模型 ID 和接口均在 `modelClient.ts`，上线前由承接方核对实际可用性。
5. 生成结果解析成三种风格的 JSON。初稿字数不合格时最多重试一次，重试结果没有再次强制验证字数。
6. 浏览器显示结果，复制操作只复制句子。换句时发送当前文字与心情、风格名和旧句列表。

| 配置 | 含义 |
| --- | --- |
| `MODEL_API_KEY` | 服务端模型密钥，由所有者在自己的部署环境配置 |
| `FAKE_MODEL=1` | 本地返回固定桩数据，避免调用收费模型；正式环境应关闭 |
| `BASE_URL` | 仅供辅助脚本选择接口地址，默认 `http://localhost:3000` |

历史部署采用 Vercel。历史体验地址为 `https://sanju-two.vercel.app`，需接收方重新确认当前可访问性。正式 App 所需服务器、域名、托管协作权限和模型账号由双方另行交接；本包移除了原部署账号及项目绑定信息。

## 当前接口

路径：`POST /api/generate`。请求头：`Content-Type: application/json`。

生成示例：

```json
{"mood":"怅然","scene":"黄昏的海边"}
```

也可提供 `image` 字段，值为压缩后的 `data:image/jpeg;base64,...` 等图片 data URL。服务器允许 JPEG、PNG、WEBP，解码后不超过 500 KiB。`scene` 和 `image` 至少一项，`mood` 为非空字符串。

成功响应结构示意如下，字符串仅说明字段：

```json
{"鲁迅":"生成的句子","莎士比亚":"生成的句子","江南":"生成的句子"}
```

单句重写示例：

```json
{"mood":"怅然","scene":"黄昏的海边","replaceStyle":"鲁迅","previous":["之前生成过的一句"]}
```

`replaceStyle` 必须为三个风格名之一，`previous` 接受旧句字符串或非空旧句列表。成功仅返回所选风格。错误结构为 `{"error":"中文提示"}`；常见状态为 400（输入）、429（预算或频率）、500/502（生成或解析失败）。

服务器用 `sanju_vid` Cookie 标记访问者，设置 HttpOnly、SameSite=Lax、有效期一年。它不是登录凭据或可信身份，原生客户端如继续使用该接口，需要明确 Cookie 的保存策略和服务端防滥用方案。路由的 `maxDuration` 为 60 秒；托管平台配置及客户端等待体验需一起验证。

## 限额的实际含义

`config.ts` 当前每访问者每分钟最多 3 个已消费预算的请求，每进程每天最多 4 个，按 UTC 日期切换。生成和换句共同消费预算；模型失败也消耗预算。字数重试发生在预算计数内部，单次请求可能调用模型两次。

计数存在进程内存中，重启会清零，多实例之间不共享；Cookie 也可被更换。因此它不能作为公开 App 的可靠成本上限。前端显示的三次换句限制也没有服务端强制保证。正式运营需要服务商预算上限、共享限流和合理的匿名身份方案。

## 图片日志和持久化

当前生成路由只记录收到图片的大概 KiB 和重试提示，未主动把图片 base64、画面文字或结果写入应用日志，也未写入数据库或磁盘。图片与文字仍发送给 OpenRouter 及实际模型服务商。部署日志、服务商留存及训练设置需按正式使用的账号和路由逐项确认。

## 辅助脚本

- `npm run try -- <图片路径> <心情> [画面描述]`：请求已启动的后端。脚本直接读图，不经过前端压缩，请自行选用不超过服务器上限的测试图。本包不含旧测试照片。
- `node scripts/rate-limit-check.mjs`：先用 `FAKE_MODEL=1` 启动一个全新本地服务再运行。脚本含约 61 秒窗口等待，并占用当前进程每日预算。
- `node scripts/style-trial.mjs`：连续请求十组文字用例。当前每日四次预算会阻止完整运行；需要开发者在本地桩模式或受控测试配置下调整预算，避免直接消耗正式模型费用。
