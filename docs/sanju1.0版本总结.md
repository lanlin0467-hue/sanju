> 对应分支：`sanju1.0`

> 整理日期：2026-10-08

## 1. 这个版本做了哪些功能

- **输入画面**：上传图片，或写文字场景；两者可同时用。
- **识图生成**：上传图片后，首次「生成」会把图发给多模态模型，作为画面依据。
- **输入心情**：自由文字，必填。
- **三句输出**：鲁迅 / 莎士比亚（朱生豪式）/ 江南，各一句；字数约 16–25（标点不计），不合格会自动重试一次。
- **复制**：每句可一键复制文字。
- **换这句**：只重写某一种风格；三种风格合计最多换 3 次；改画面/心情后**重新点「生成」**才恢复次数。
- **隐私提示**：点「选择图片」时拦截一次，文案为「上传图片请注意隐私与备份，本站不留存您的图片」。
- **本站不留存图片**：不落盘；日志只记「收到图片 xx KB」。
- **图片压缩**：前端压缩后再上传（上限约 500KB）。
- **限流**：同一访问者每分钟最多 3 次写手调用；全站每天最多 4 次（可在配置里改）。
- **手机布局**：窄屏、较大触控、安全区；另有可选的「添加到主屏幕」提示（PWA 相关）。
- **已部署到 Vercel**：密钥用环境变量 `MODEL_API_KEY`，未进前端包。

## 2. 已知限制 / 还没做完

| 项 | 说明 |
|---|---|
| 大陆手机 / 微信访问 | 站点在 Vercel，国内流量、微信内置浏览器常打不开或不稳；朋友圈主场景未闭环。 |
| 「换这句」不带图 | 换句请求只传文字，不传图片；**只上传照片、没写画面描述**时，换句容易跑偏。 |
| 文案质量 | 靠 prompt + 模型，无自动质量验收；偶发偏题或空泛。 |
| 微信真机验收 | 任务 22（微信内复制到朋友圈、iPhone 原图等）未正式打勾完成。 |
| 隐私文案完整度 | 「本站不留存」对本站成立；图仍会到 OpenRouter / 下游模型。正式对公众上线前建议改提示（见 `docs/上线核对.md`）。 |
| 限流实现 | 用进程内内存计数；Vercel 多实例下**不严格**，每日 4 次挡不住跨实例。 |
| 模型账号 | 当前是**借来的** OpenRouter Key，余额有限，不是自有账号后台。 |
| 合规 / 备案 | 面向大陆公众长期上线需换境内托管与模型，并处理备案等（见上线核对）。 |
| 需求里「先不做」 | 账号历史、分享图、更多文风、点赞收藏、长度可调、整批换三句等——**故意未做**。 |

## 3. 怎么运行这个项目

### 环境

- Node.js（建议 20+；本机曾用 24.x）
- 一把可用的 OpenRouter API Key（变量名 `MODEL_API_KEY`）

### 本地步骤

```bash
# 1. 进入项目
cd /path/to/sanju   # 或本机「文案对比」目录

# 2. 切到本版分支
git checkout sanju1.0

# 3. 安装依赖
npm install

# 4. 配置密钥（不要提交 .env.local）
cp .env.example .env.local
# 编辑 .env.local，填入：
# MODEL_API_KEY=你的密钥

# 5. 开发模式
npm run dev
# 浏览器打开 http://localhost:3000
```

### 常用命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 本地开发 |
| `npm run build` && `npm start` | 本地生产构建并启动 |
| `npm test` | 跑 vitest（字数、限流等单测） |
| `FAKE_MODEL=1 npm run dev` | 不调真模型，用桩数据测前台/限流（测完记得去掉） |

### 已绑定 Vercel 时（可选）

```bash
# 需已 vercel login，且项目已 link 到 lan-lin/sanju
vercel env ls --scope lan-lin --project sanju
vercel deploy --prod --scope lan-lin --project sanju
```

线上密钥只配在 Vercel 敏感环境变量里，不要写进 git。

## 4. 以后接着改：特别注意

### 容易踩坑

1. **Next.js 16 与训练数据不同**  
   以仓库内 `AGENTS.md` 和 `node_modules/next/dist/docs/` 为准，不要按旧版 Next 习惯硬套。

2. **换句务必带图（若要修）**  
   入口在 `HomeForm` 的 `onReplace` 与 `src/app/api/generate/route.ts` 的 replace 分支；现在 replace **不走** `toContent(..., image)`。

3. **字数与配置只改一处**  
   16–25、压缩上限、限流次数、换句次数：统一在 `src/lib/config.ts`。

4. **提示词只放 `src/lib/prompt.ts`**  
   改风格腔调、样例、JSON 输出格式从这里改；`modelClient.ts` 只管调 OpenRouter。

5. **生成可能 30s+**  
   路由已设 `maxDuration = 60`。前台已对非 JSON 响应做了容错；仍可能因平台超时看到失败文案。

6. **限流别当生产级防护**  
   `src/lib/rateLimit.ts` 是内存表。上公网要换 Redis / 平台级限流，并视预算调高 `limits.daily`。

7. **密钥与 `.env.local`**  
   `.gitignore` 已忽略 `.env*`；`vercel link` 可能往 `.env.local` 写入 `VERCEL_OIDC_TOKEN`，勿提交。部署时用 `outputFileTracingExcludes` 避免把本地 env 打进函数包（见 `next.config.ts`）。

8. **隐私文案若改字**  
   需求文档写死了一句；改前台 `PRIVACY_TEXT` 时同步改需求/验收预期，并对照 `docs/上线核对.md`。

### 临时方案 → 以后建议替换

| 现状（临时） | 建议替换 |
|---|---|
| 托管：Vercel | 大陆用户为主时 → 境内云 + 备案域名 |
| 模型：OpenRouter `qwen/qwen3.7-flash` + 借来的 Key | 自有账号，或国内识图模型（通义/豆包等） |
| 日限额 4、内存限流 | 按真实预算调数字；限流落到共享存储 |
| 匿名临时部署记录 | 以 `docs/部署记录.md` 里正式 `lan-lin/sanju` 为准；旧临时 URL 可忽略 |
| 合规提示只说「本站不留存」 | 对公众上线前补充第三方处理说明 |
