# 需求文档(草稿 v1.0)

> 状态:草稿。凡标注【待确认】的内容,尚未决定。

## 0. 一句话描述(原文)

一个把"画面和情绪"变成三种文风(鲁迅 / 莎士比亚 / 江南)文案的小工具,让想给生活留记号的人,不用自己憋词,从三个味道里挑一句直接用。

## 1. 核心功能点

1. 输入"画面":支持两种方式,上传图片,或用文字描述一个场景;上传图片的同时允许补充文字描述。
2. 图片识别:用户上传图片后,系统识别图片内容,作为生成文案的画面依据。
3. 输入"情绪":用户自由输入文字。
4. "画面"和"情绪"均为必填,缺一不可提交。
5. 生成三种文风的文案,每种文风各输出一句,共三句,每句固定 20 字左右:
   - 鲁迅:冷峻讽刺的笔调
   - 莎士比亚:朱生豪式译本的腔调
   - 江南:《龙族》作者江南的文字风格
   - 三种风格均未提供示例文本。
6. 生成结果要与用户给出的画面和情绪相对应。
7. 用户从三句中选一句,点击复制文字直接使用。
8. "换一批":每次只单换其中一种风格的那一句,不提供一次整体重新生成三句。
   - 换一批的次数限制为 3 次,三种风格合计计算。
   - 用户修改画面或情绪后,次数重新计算。
9. 点击上传图片的当下,展示隐私提示(见第 4 节)。

## 2. 目标用户

想给生活留记号、不想自己憋词的人,按优先级排序:

1. 爱发朋友圈的年轻人(最优先)
2. 发小红书、抖音的人
3. 写日记的人

## 3. 最核心的使用场景

- 核心场景:用户想发一条朋友圈,手里有一张照片或一个想记录的画面,加上一种情绪,但想不出合适的配文。打开网页,输入画面和情绪,得到三种风格各一句(约 20 字),复制其中一句发朋友圈。
- 其次场景:为小红书、抖音内容配文。
- 再次场景:写日记。
- 其他文案去向(照片配文等)按原描述保留,不单独设计。
- 产品形态:网页。

## 4. 非功能要求

- 网页版需要在手机浏览器里好用(核心用户主要在手机上使用)。
- 图片隐私:
  - 本站不留存用户上传的图片。
  - 点击上传的当下,展示隐私提示,文案为:"上传图片请注意隐私与备份,本站不留存您的图片"。

## 5. 这一版先不做

- 账号体系和历史记录
- 一键生成分享图 / 文字卡片(只支持复制文字)
- 更多文风,或让用户自定义文风(只做鲁迅、莎士比亚、江南三种)
- 分享链接、点赞、收藏、用户反馈
- 文案长度可调(这一版固定 20 字左右,以后再说)
- 图片保存与用户主动删除图片(因不留存图片,不需要)
- 一次整体重新生成三句(换一批只支持单换一种风格)
