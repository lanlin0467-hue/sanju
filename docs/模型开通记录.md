## 这意味着什么

- 你**进不了**对方的 Keys / Credits 后台,所以没法自己设「每月消费上限」。
- 花的钱记在**对方账号**上。用之前跟对方说清楚,并请对方设好限额或只留一小笔余额。
- Key 可能随时被对方作废或改权限。坏了就换一把,或以后换成你自己的号。
- 上传的图片会经过 OpenRouter 和对方账号侧的服务商,隐私上要心里有数。
