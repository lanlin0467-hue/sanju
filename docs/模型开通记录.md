## 这意味着什么

- 你**进不了**对方的 Keys / Credits 后台,所以没法自己设「每月消费上限」。
- 花的钱记在**对方账号**上。用之前跟对方说清楚,并请对方在 OpenRouter 里设好限额或只留一小笔余额。
- Key 可能随时被对方作废或改权限。坏了就换一把,或以后换成你自己的号。
- 上传的图片会经过 OpenRouter 和对方账号侧的服务商,隐私上要心里有数。

## 你这个情况怎么验收

### 1. 确认你手里有 Key

- 本地有一串 OpenRouter Key(一般以 `sk-or-` 开头)。
- 先存在密码管理器或记事本,任务 4 再放进 `.env.local`。
- **不要**发给我,也不要写进仓库。

验收:你自己打开记事本 / 密码管理器,能看到这串 Key。

### 2. 消费上限(请对方做,或先用项目自己的限额顶上)

优先请账号主人做一件:
- 在 [OpenRouter Credits / Limits](https://openrouter.ai/settings/credits) 设用量上限,或账户只留一小笔 Credits、关掉自动充值。

若对方暂时不方便设:
- 先记一笔「上限由账号主人控制,项目侧每日最多调写手 4 次」(任务清单已定)。
- 真正接到代码后(任务 4 / 19),靠项目限流 + 少测几次控制花费。

把现状记在下面(二选一或都写):

- 对方已设的限额 / 余额:约 **10 人民币**(对方账号余额;不是你自己设的月限额)
- 设置日期:2026-10-08

### 3. 试用看图(可选)

如果你打得开 [OpenRouter Chat](https://openrouter.ai/chat) 并能选模型,上传一张图试一句即可。  
打不开或没有登录对方账号:这一步跳过,任务 4 用这把 Key 调接口时再验。
