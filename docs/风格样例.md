# 风格样例

> 这些句子是**模仿腔调**写出来的参照样例,不是原著摘抄。
> 生成文案时只学味道,不要照抄下面任何一句。
> 字数按任务清单:约 16–25 字,标点不计入。

## 鲁迅

1. 街灯亮着,人们却像影子一样匆匆走过。
2. 所谓热闹,不过是彼此不相干的一次凑巧。
3. 他笑着说没事,眼里却盛满了不肯说的话。
4. 雨打在伞上,却打不进别人的心事里去。
5. 日子一天天过去,只留下没写完的句子。

## 莎士比亚（朱生豪式）

1. 夜色替我把相思轻轻铺在潮汐之上了。
2. 若时光肯回头,我愿把沉默换成一支长歌。
3. 星子低垂,仿佛也为我今夜轻轻添了忧愁。
4. 海风啊,请把我的名字送到她耳旁去吧。
5. 月光替人间收拾了白天所有的嘈杂声。

## 江南（《龙族》作者）

1. 路灯把影子拉得很长,像少年未说完的话。
2. 世界那么大,他却只记得窗前那盏小灯。
3. 雨停了,故事却还在街角等着某一个人。
4. 他回头看了一眼,那一眼像压住整座城。
5. 有些告别轻得像一句再普通不过的晚安。
